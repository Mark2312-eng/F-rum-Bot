VISE RUSSIA

Политика конфиденциальности

Версия документа: 27 ноября 2026 года.

Информационный документ проекта. Перед использованием в качестве юридически значимого документа администрация должна указать полные сведения об операторе данных и проверить требования законодательства, применимого к пользователям и проекту.

1. Какие данные обрабатываются

В зависимости от используемых функций бот и сайт могут обрабатывать Telegram ID, имя и username Telegram, факт и дату согласия с документами, выбор подписки на уведомления, сообщения и команды, сведения об активности в подключённых группах, обращения в поддержку, жалобы, результаты тестирования и записи о действиях модерации.

2. Для чего используются данные

  • для работы Telegram-бота и предоставления запрошенных функций;
  • для модерации подключённых сообществ, обработки жалоб и обеспечения безопасности;
  • для организации заявок, собеседований и тестирования команды;
  • для отправки информационных обновлений только пользователям, которые отдельно подписались на рассылку;
  • для предотвращения злоупотреблений и диагностики технических ошибок.

3. Передача и хранение

Бот использует платформу Telegram для обмена сообщениями. Данные, необходимые для работы сервиса, могут храниться в базе данных проекта на инфраструктуре Render. Сайт и бот могут обращаться к форуму VISE RUSSIA на XenForo для выполнения запрошенных функций. Не вводите в бот пароли, платёжные данные или иные сведения, не необходимые для его работы.

Проект не заявляет о продаже персональных данных. Доступ к данным должен предоставляться только уполномоченным лицам в объёме, необходимом для работы проекта.

4. Срок хранения

Данные хранятся столько, сколько необходимо для работы соответствующих функций, выполнения требований безопасности и ведения журналов. Пользователь может отозвать согласие через команду /withdraw_consent. Отписка от рассылки через /stop отключает уведомления, но сама по себе не удаляет остальные данные.

5. Выбор пользователя

Согласие на обработку данных и подписка на информационные рассылки — разные действия. Подписка добровольна. Команда /stop отключает рассылку. Команда /withdraw_consent удаляет запись о согласии и подписке из базы данных бота; для повторного использования функций, требующих согласия, потребуется подтвердить его снова.

6. Контакт

По вопросам конфиденциальности обратитесь через Telegram-бот VISE RUSSIA: @ViseRussiaHelpForumBot. Администрации проекта следует дополнить этот раздел официальными реквизитами и контактами оператора до публикации юридически значимой версии документа.
