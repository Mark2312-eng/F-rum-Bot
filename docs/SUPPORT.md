# Единая система поддержки

## Что входит

- Публичный сайт: вход через Telegram Login, создание обращений, история и переписка.
- Telegram: команда `/support`, создание обращения кнопкой, список обращений и уведомления.
- Закрытая панель: очередь, просмотр переписки, ответы и закрытие обращений.
- Системные роли: доступ к очереди имеют владелец, `support`, `support_lead` и другие роли с разрешением `support`.
- Жалобы модерации `/report` остаются отдельной системой и не смешиваются с тикетами поддержки.

## Настройка Telegram Login

Вход на публичном сайте открывается во всплывающем окне на уже используемом домене панели:
`https://f-rum-bot-panel.onrender.com/support-login.html`.

Так сохраняется существующая привязка Telegram Login к домену панели. Не меняйте `/setdomain` на домен публичного сайта: это может нарушить текущий вход в закрытую панель. Popup передаёт подтверждённые Telegram данные обратно на публичный сайт, а backend проверяет подпись и создаёт отдельную пользовательскую сессию.

## Переменные Render

Обязательные переменные уже используемого backend:
- `TELEGRAM_BOT_TOKEN` — секрет бота; хранить только в Render.
- `PANEL_SESSION_SECRET` — секрет подписи cookie, минимум 32 символа.
- `ADMIN_TELEGRAM_ID` — ID владельца панели.
- `OWNER_TELEGRAM_ID` — ID владельца бота.
- `PANEL_ORIGIN=https://f-rum-bot-panel.onrender.com`.
- `PANEL_BOT_USERNAME=ViseRussiaHelpForumBot`.

Необязательная переменная:
- `PUBLIC_SITE_ORIGIN=https://f-rum-bot-info.onrender.com` (это значение используется по умолчанию).

Новая схема PostgreSQL создаётся автоматически при старте backend. Отдельные миграции вручную не нужны.

## Как пользоваться

### Участник
- На сайте откройте раздел «Поддержка» и войдите через Telegram.
- Создайте обращение, затем открывайте его из списка, чтобы читать ответы и писать продолжение.
- В Telegram откройте бота, нажмите Start, затем выполните `/support`.

### Сотрудник поддержки
- Назначьте пользователю системную роль `support` или `support_lead`.
- В Telegram используйте `/supportqueue`, `/supportreply ID текст` и `/supportclose ID`.
- Войдите в закрытую панель через Telegram. Раздел «Поддержка» показывает очередь и переписку; доступ проверяется сервером по системной роли.

Для получения личных уведомлений пользователь должен хотя бы один раз запустить бота через Start. Telegram не позволяет боту первым написать пользователю.
